## Step 0.3 scope and acceptance

Build the responsive web shell from Stitch S02, using semantic visual tokens and fictional preview content only. Desktop uses the horizontal workspace navigation and command-centre composition; narrow layouts use a labelled five-item bottom navigation. Private captures and explicitly shared excerpts have different visible labels. The denied-access preview explains a generic recovery path without loading or identifying private records. Unbuilt workspace destinations are clearly marked unavailable and contain no account content. Stitch S03 remains the visual reference for the later private-capture step. See [the design implementation record](Cadence-Design-Implementation.md).

The shell does not authenticate users or enforce authorization; this remains an explicit later gate. Avoid user-content persistence, external fonts/images, analytics and service workers. Render page responses dynamically with `Cache-Control: private, no-store`, and use no-index metadata/headers. The profile and workspace labels, drafts and activity shown in the interface are synthetic fixtures.
